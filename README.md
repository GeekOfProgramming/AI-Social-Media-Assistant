## About This Project
This project is a conversational AI assistant designed to automate customer support and engagement across multiple social media platforms. It centralizes incoming messages from Meta (Instagram, WhatsApp) and Telegram and uses AI to provide intelligent, automated responses.

## Core Features
* **Multi-Platform Integration:** Connects to Meta (Instagram, WhatsApp) and Telegram APIs for centralized message handling.
* **Conversational AI:** Leverages AI (e.g., OpenAI API) to understand and reply to user queries.
* **React Dashboard:** A complete management dashboard built with **React.js** for bot configuration, monitoring conversations, and viewing analytics.
* **Automation:** Uses **n8n** workflows for complex, low-code automation sequences.

## Tech Stack
* **Frontend:** React.js, TypeScript (یا JavaScript), CSS/SASS
* **Backend/Automation:** Node.js (یا Python), n8n
* **APIs:** Meta API, Telegram Bot API, OpenAI API
